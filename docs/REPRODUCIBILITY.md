# Reproducibility

## Deterministic default run

The committed benchmark uses:

- simulator seed: `42`;
- 60 fish per arm;
- 70%/30% fish-level split;
- HMM candidates: 2, 3, and 4 states;
- three train-only cross-validation folds;
- 1,000 bootstrap iterations for forecast intervals.

Run the complete workflow with:

```bash
python -m tbi_markov
```

## Real-recording run

The real analysis uses the same seed, split fraction, candidate state counts,
CV folds, and bootstrap count as the synthetic benchmark:

```bash
tbi-real
```

It rewrites `data/real/` from the source workbooks and writes `results_real/`.
Because the real cohort has no planted latent state, the run produces
`state_recovery: null` and omits the confusion-matrix figure; every other output
has the same shape as the synthetic run. The source workbooks are the only
non-regenerable input — if they are absent, the real-data tests skip rather than
fail.

## Output contract

The pipeline writes:

```text
data/synthetic/
├── tbi_4_6dpf_lfp_timeseries.csv
├── tbi_4_6dpf_fish_outcomes.csv
├── tbi_4_6dpf_dlc_behavior.csv
└── tbi_4_6dpf_dataset_manifest.json

results/
├── figures/
├── tables/
├── TBI_MODEL_RESULTS.md
└── tbi_model_metrics.json
```

The workbook is not regenerated by the Python pipeline. It is a formatted
human-readable snapshot of the default CSV cohort.

## Integrity controls

- The manifest records SHA-256 hashes for each normalized CSV.
- Same-seed generation is tested for byte-stable table content.
- Feature allowlisting prevents protocol, dose, behavior, or truth leakage.
- Preprocessing is fit on training fish only.
- Train/test fish IDs are disjoint.
- QC gaps terminate sequences instead of shortening time.
- Prefix invariance ensures a DPF5 forecast does not depend on DPF6 features.
- Forecast tests verify the transition-matrix propagation horizon.

## Verification

```bash
python -m pytest
python -m compileall -q src scripts
```

CI repeats these checks across supported Python versions on every push and pull
request.

## Custom runs

```bash
tbi-generate --seed 101 --n-per-arm 80
tbi-analyze --seed 101 --test-fraction 0.30 --states 2 3 4
```

Custom runs overwrite the normalized CSVs and result artifacts. Use a clean Git
worktree or copy the committed seed-42 outputs before experimenting if both
versions must be retained.
