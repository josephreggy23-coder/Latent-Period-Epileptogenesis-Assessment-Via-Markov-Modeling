# Results

Outputs of the analysis in `src/tbi_markov`, regenerated by `tbi-analyze`.
Everything here is derived from the source workbooks and safe to delete.

## Top-level

- `TBI_MODEL_RESULTS.md`: human-readable report and scientific limits.
- `tbi_model_metrics.json`: machine-readable configuration, preprocessing,
  state mapping, model selection, forecast, calibration, dynamics, and
  behavioral-validation metrics.

## Figures

`figures/` contains model-order selection, the causal 6 dpf forecast ROC curve,
held-out state trajectories, the ordered transition matrix, and the behavioral
validation scatter.

There is no state-recovery confusion matrix. These are real animals with no
latent-state ground truth, so inferred states have nothing to be scored
against; the figure is absent by design rather than missing.

## Tables

`tables/` contains the split assignments, scored held-out sessions, per-fish
forecasts, state occupancy, group transition summaries, and the ordered
transition matrix.
